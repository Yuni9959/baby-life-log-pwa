TouchBebe: explicit health information disclosure

Current remediation for com.yuni.touchbebe, prepared October 24, 2026. The optional Bixby recording feature uses AccessibilityService API and is not an accessibility tool (isAccessibilityTool=false).

Open current review video · Privacy policy

What changed

A separate in-app disclosure now explicitly names health information, lists the data accessed, and explains its use, storage and sharing before requesting access. Existing version-1 consent does not authorize reading or saving after this update. Users must affirmatively accept the new version-2 disclosure. Decline, Back and closing the dialog do not grant access. Manual recording and example practice remain available.

Full disclosure translation

Title: Consent to access and use health information.

TouchBebe uses AccessibilityService API to read the current recognized sentence on Bixby's screen. It also operates when the app is not open, when you speak to Bixby.

Data read: The baby's name/nickname, health information (feeding type, amount and time; burping; sleep; diapers and excretion; body temperature; medicine name, dose and unit; symptoms; vaccinations), record time and notes contained in the sentence.

Purpose: Automatically save baby records from the spoken content and process explicitly requested deletion of the previous record or correction of its time. Saved records support daily reports, statistics and care reminders.

Storage and sharing: Created records are stored on the phone. If connected to a family account, they synchronize to TouchBebe's server and can be viewed by connected family members. They are not used for advertising or sold.

Original audio and full recognized sentences are not automatically retained or transmitted. Dictated notes are saved as records. Improvement phrases explicitly submitted by the user are transmitted according to their separate notice. Bixby's voice processing follows Samsung's settings. Content on other apps' screens is not read.

You can use manual recording and example practice without agreeing. Automatic recording can be disabled at any time under Management → Permissions and Bixby settings.

Optional switch: Allow recording while locked. The baby's name and record result may appear on the lock screen. If result voice is enabled, the result is also spoken. Buttons: Agree and connect / Do not agree.

Review demonstration

The current video shows the debug build of source 68b5e42, containing the production disclosure and service changes. It uses a dedicated Android emulator and synthetic baby records. Its Bixby input fixture is an isolated test application, not Samsung Bixby and not part of the distributed app. The fixture emits Android accessibility events through the actual TouchBebe service, local interpreter and persistent recording path. It does not demonstrate Samsung wake-word or microphone recognition. The screen recording is continuous, with no audio; English captions are added beneath it. Android Settings also lists the older release retained on this emulator for upgrade tests.

Historical real-Samsung demonstrations are available for context: original spoken input and Android grant and optional dismissal. Their earlier disclosure wording is superseded by the current disclosure above.

Service boundaries

The service is limited to the current visible user-input node in com.samsung.android.bixby.agent. Previous conversation and assistant answers are not command sources. Consent, baby scope, Bixby version, lock permission and freshness are checked before reading and again before committing. Local classification and fixed validation rules process explicit care statements; the app does not initiate goals, plan or navigate arbitrary interfaces.

The separate optional “close Bixby after recording” consent permits one fixed Back action after a newly saved nonduplicate record, only on the same unlocked Bixby processing window. The existing separate choice cannot bypass the renewed health-data consent. Automatic recording and the optional closing action can be disabled independently.
