터치베베 계정·데이터 삭제 요청

앱을 다시 설치하지 않아도 요청할 수 있습니다. 계정 전체 또는 음성 인식 개선 자료만 삭제하도록 선택할 수 있습니다.

이메일로 요청하기

  1. 로그인에 연결한 이메일에서 아래 주소로 요청해 주세요. 제목은 ‘터치베베 계정·데이터 삭제 요청’으로 적어 주세요.
  2. 삭제할 범위를 알려 주세요: 계정과 연결된 개인정보 전체 / 음성 개선 자료만.
  3. 이메일을 연결하지 않은 익명 계정은 앱의 가족·계정 → 계정·데이터 삭제 요청 → 요청 내용 복사로 내 계정 코드를 포함할 수 있습니다. 확인이 어려우면 이메일로 문의해 주세요.

메일 작성하기

메일 앱이 열리지 않으면 주소를 복사해 이용 중인 이메일에서 보내 주세요.
touchbebeinfo@gmail.com

비밀번호, 인증 토큰, 가족 초대 코드, 아기 건강 기록 전체는 보내지 마세요. 이메일로 요청하는 경우 메일을 보내기 전까지 접수되지 않습니다. iPhone 앱에서 직접 접수한 경우에는 추가 이메일을 보내지 않아도 됩니다.

어떤 정보가 삭제되나요?

본인 확인 후 계정·로그인 연결 정보, 본인의 가족 멤버십과 개인정보, 제출한 개선 자료를 삭제 대상으로 처리합니다. 가족이 공동으로 사용하는 아기 기록은 다른 보호자의 정보와 권리를 함께 확인하여 삭제할 범위를 안내합니다. 본인에게만 속하는 가족·아기 기록은 함께 삭제를 요청할 수 있습니다.

본인과 삭제 범위를 확인한 후 30일 이내 처리 결과를 회신합니다. 운영 데이터베이스의 암호화 백업은 7일 보관하므로 서버 삭제 후 남은 백업 사본도 최대 7일 내 만료됩니다. 복구 시에는 완료된 삭제 요청을 다시 반영합니다.

휴대폰 기록과 로그아웃은 달라요

앱 삭제나 로그아웃은 서버 계정 삭제가 아닙니다. 휴대폰에만 있는 위젯 사진·유축 기록과 별도로 저장한 PDF·JSON·CSV 사본은 해당 기기나 저장 위치에서 직접 삭제해 주세요. 삭제 전에 보관할 자료가 있으면 앱의 관리 → 백업·복원에서 저장할 수 있습니다.

‘현재 아기의 기록 모두 삭제’는 연결된 가족에게도 기록 삭제 상태를 동기화하는 기능이며, 서버 계정의 완전 삭제 요청과는 다릅니다.

iPhone 앱에서 직접 요청하기

가족 또는 관리 → 계정·데이터 삭제 요청에서 삭제할 계정으로 로그인한 뒤 ‘계정 삭제 요청 보내기’를 선택하세요. 별도의 이메일 발송 없이 접수 번호와 처리 예정일을 확인할 수 있습니다. 운영자가 30일 이내 처리합니다. 접수한 기기에서 삭제 후에도 처리 상태를 확인할 수 있고, 이메일을 연결했다면 해당 주소로도 결과를 안내합니다.

연결된 로그인 수단과 본인이 작성한 서버 기록을 삭제합니다. 다른 보호자가 없는 가족·아기 정보도 삭제합니다. 다른 보호자가 남아 있는 가족과 그 보호자의 기록은 유지하며 공유 기기에 삭제를 알리기 위한 내용 없는 표식은 남을 수 있습니다. Apple 로그인 연결도 해제합니다.
