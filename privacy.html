터치베베 개인정보처리방침

시행일: 2026년 10월 13일 · Android 터치베베의 현재 데이터 처리 기준

터치베베는 보호자가 아기의 생활과 건강 관찰 내용을 기록하고 선택한 가족과 공유하도록 돕습니다. 기기에만 저장되는 정보와 서버에 전송되는 정보를 구분해 안내합니다.

1. 처리하는 정보와 목적

정보목적과 보관 위치
아기 이름·생년월일 등 입력한 프로필, 수유량·모유 수유 시간, 수면·배설·트림·울음, 체온·측정 시각, 투약·예방접종·증상·보호자 메모기록 조회·생활 분석·진료 참고 PDF 제작에 사용합니다. 기본적으로 휴대폰에 보관하며, 가족 공유를 연결하면 해당 가족의 프로필과 기록을 Supabase 서버에 동기화합니다. 연결된 가족은 부여된 권한으로 볼 수 있습니다.
Google·Kakao 로그인 식별자, 이메일 및 로그인 제공자가 전달하는 이름·프로필 정보(프로필 사진 주소 포함), 익명 로그인 식별자, 계정·가족 연결 정보로그인, 기기 간 복원, 가족 권한 확인에 사용합니다. 가족 공유와 개선 의견 전송에는 익명 계정이 사용될 수도 있습니다. 인증 정보는 기기와 인증 서버에서 처리합니다.
앱에서 생성한 임의 기기 식별자와 기기 모델명, 동기화 요청·사용 기록가족 연결·기기 구분·기록 동기화와 오류·접근 통제에 사용합니다. 기기 식별자는 광고 ID나 전화번호가 아닙니다.
위젯에 선택한 사진·문구·편집 설정사진 위젯을 표시하기 위해 기기에 보관합니다. 현재 Android 앱은 선택한 위젯 사진을 가족 서버에 업로드하지 않습니다.
엄마의 유축 기록·타이머·알림 설정, 알림·화면·음성 기능 설정선택한 기능을 실행하기 위해 기기에 보관합니다. 유축 기록은 현재 가족 서버에 동기화하지 않습니다.
직접 작성하고 전송을 선택한 음성 인식 개선 문장, 제출 식별자, 앱·모델 버전, 로그인 식별자와 접수 시각인식 오류를 검토하고 향후 모델을 개선하기 위해 Supabase에 보관합니다. 자동 수집한 음성 원문이 아닙니다.
서버 요청 시각·상태 코드 등 운영 정보, 접속 IP 및 IP에서 추정한 대략적인 지역 등 서비스 제공자가 생성하는 접속 로그서비스 제공·접근 통제·오류 및 부정 사용 대응에 사용합니다. GPS로 위치를 수집하지 않습니다. 운영 알림에는 아기 이름, 기록 내용, 이메일, IP, 음성 원문을 넣지 않고 집계된 상태와 확인 링크만 사용합니다.

현재 Android 앱에는 광고 SDK, 맞춤형 광고, 인앱 결제가 없습니다. 연락처·위치·카메라 촬영 권한을 요청하지 않습니다. 위젯 사진은 시스템 사진 선택 화면에서 사용자가 고릅니다. 변경 시 실제 처리 내용과 안내를 함께 갱신합니다.

2. 음성 기록·접근성 권한

‘빅스비 첫 문장 기록’은 별도 설명에 동의하고 Android 접근성 설정에서 직접 켜는 선택 기능입니다. 빅스비 화면의 현재 인식 문장만 읽으며 다른 앱 화면은 읽거나 조작하지 않습니다. 기기 안의 JEV 모델과 검증 규칙이 명확한 돌봄 문장을 기록으로 바꾸고, 불명확한 내용은 저장하지 않습니다.

‘기록 후 빅스비 닫기’에 별도로 동의하면 잠금이 풀린 상태에서 새 기록이 저장된 직후, 같은 빅스비 창에 뒤로가기를 한 번 요청합니다. 다른 앱은 닫지 않으며, 이미 시작된 답변이나 다른 앱 실행을 모두 중단하는 기능은 아닙니다.

터치베베는 자동 인식 원문과 원본 음성을 보관하거나 외부 AI 서비스로 전송하지 않습니다. 만들어진 기록과 최근 저장 결과는 앱에 보관되며 가족 공유 설정을 따릅니다. 빅스비와 Android 음성 인식 서비스의 음성 처리는 해당 서비스 제공자와 기기의 설정·정책을 따릅니다.

앱 안에서 음성 입력을 선택하면 마이크를 사용합니다. 알림 권한은 돌봄·유축 알림에, ‘알람 및 리마인더’ 설정은 선택한 유축 타이머·알림을 제때 전달하는 데 사용합니다. 거부해도 직접 기록할 수 있습니다.

잠금 상태 기록과 결과 표시는 별도 허용 시에만 사용합니다. 아기 이름이나 기록 결과가 잠금 화면에 표시될 수 있습니다. 저장 결과 음성 안내는 기본 꺼짐이며 사용자가 켜면 기기에서 소리로 안내합니다. 앱의 끄기 기능 또는 Android 설정에서 언제든 권한을 해제할 수 있습니다.

3. 음성 개선 의견

‘업데이트 때 전송하도록 모으기’를 선택한 문장은 기기에 보관한 뒤 이후 앱 업데이트 후 인터넷 연결 시 전송합니다. 이름·연락처·건강 정보 등 개인정보는 문장에 적지 말아 주세요. 아기 이름·가족 식별자·원본 음성·자동 인식 원문은 자동 첨부하지 않습니다.

기기에는 최대 50개, 서버에는 로그인 식별자당 최대 500개를 보관합니다. 전송 전 삭제하면 전송하지 않습니다. 전송 후 ‘기기에서 삭제’는 기기 사본만 삭제하므로 서버 자료 삭제는 아래 문의처에서 요청해 주세요. 서버 자료는 삭제 요청 또는 계정 삭제 시 함께 처리합니다. 다른 앱 사용자에게 공개하거나 자동으로 모델에 학습시키지 않습니다.

4. 공유와 외부 서비스

기록은 사용자가 연결한 가족에게 공유됩니다. PDF·CSV·JSON 또는 텍스트 공유를 직접 선택하면 선택한 앱이나 저장 위치로 전달됩니다. 이미 전달·저장된 사본은 수신자나 사용자가 관리해야 합니다.

  • Supabase: 로그인·가족 데이터 저장과 동기화. 현재 프로젝트 데이터베이스는 일본 도쿄 리전에 있습니다. Supabase 개인정보처리방침
  • GitHub: 공개 안내 페이지와 비공개 저장소의 암호화 운영 백업 보관. 복호화 개인 키는 업로드하지 않습니다. GitHub 개인정보처리방침
  • Cloudflare: 서버 상태 점검. Telegram: 운영자가 연결한 경우 장애 알림 수신. 아기 기록 본문을 이 점검·알림에 전송하지 않습니다. Cloudflare 개인정보처리방침 · Telegram 개인정보처리방침
  • Google·Kakao·삼성 및 선택한 Android 음성 인식 제공자: 사용자가 선택한 로그인·음성 기능을 각 제공자의 정책에 따라 처리합니다.

이들 해외 서비스를 이용하는 과정에서 국내 외 지역에서 정보가 처리될 수 있습니다. 정보를 판매하거나 광고 파트너에게 제공하지 않습니다.

5. 보관·삭제·백업

휴대폰 기록은 앱의 삭제 기능이나 앱 데이터 삭제로 지울 수 있습니다. 서버와 연결된 기록의 일반 삭제는 다른 가족 기기에도 반영하기 위한 삭제 표시를 사용하므로 즉시 물리 삭제와는 다릅니다. 서버 계정과 개인정보의 삭제는 계정·데이터 삭제 요청으로 신청해 주세요. 본인과 삭제 범위를 확인한 후 30일 이내 처리 결과를 안내합니다. 다른 보호자가 함께 사용하는 기록의 처리 범위도 함께 확인합니다.

운영 데이터베이스는 장애 복구를 위해 하루 한 번 암호화 백업하며 비공개 저장소에 7일간 보관합니다. 서버에서 삭제된 정보가 이전 백업에 남더라도 최대 7일 내 보관 기간이 끝납니다. 백업은 서비스 복구에만 사용하며, 복원할 경우 완료된 삭제 요청을 다시 반영한 후 서비스를 재개합니다.

접속 로그의 보관은 각 서비스의 설정과 정책을 따릅니다. 별도 보관이 필요한 법적 의무가 발생하면 해당 항목·사유·기간을 안내하며, 현재 하지 않는 결제·광고를 이유로 정보를 보관하지 않습니다. 앱 삭제나 로그아웃만으로 서버 정보가 삭제되지는 않습니다.

6. 보호 조치와 이용자 권리

서버 통신에 HTTPS, 가족별 접근 권한 검사, 기기 인증 정보 암호화, 운영 백업 암호화를 적용합니다. 보고서 공유 파일은 제한된 접근 권한과 만료 처리를 사용하지만 사용자가 다른 앱에 저장한 사본을 회수할 수는 없습니다.

본인 또는 법정대리인은 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 어린이의 기록은 보호자가 관리합니다. 본인 확인에 비밀번호·인증 토큰·아기의 건강 기록 전체를 요구하지 않습니다. 보유한 계정 정보로 확인하기 어려운 경우 필요한 최소 정보와 확인 방법을 안내합니다.
