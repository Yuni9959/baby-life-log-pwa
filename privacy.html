터치베베 개인정보처리방침

시행일: 2026년 10월 31일 · iPhone 및 가족 구성원 설정 안내 추가. Android 접근성 정보 처리와 동의 범위는 유지합니다.

터치베베는 보호자가 아기의 생활과 건강 관찰 내용을 기록하고 선택한 가족과 공유하도록 돕습니다. 기기에만 저장되는 정보와 서버에 전송되는 정보를 구분해 안내합니다.

Android와 iPhone은 같은 가족 공유 서버를 사용합니다. 가족 구성원이 선택하거나 직접 입력한 표시 이름과 읽기·쓰기 권한을 가족 식별 및 접근 관리 목적으로 서버에 보관하고 같은 가족에게 표시합니다. 새로 초대한 구성원은 읽기 전용으로 시작하며, 가족 관리자가 이름과 쓰기 권한을 변경할 수 있습니다. 기존 구성원의 권한은 자동으로 낮추지 않습니다.

iPhone용 터치베베 개인정보 처리 안내

이 항목은 iPhone용 터치베베에 적용합니다. 아래 Android 전용 Bixby·접근성 서비스 및 음성 개선 문장 제출 설명과 구분해 주세요. 운영자·개인정보 문의 책임자는 강승윤이며, 문의 주소는 touchbebeinfo@gmail.com입니다.

기록과 가족 공유

기본 기록은 로그인 없이 기기에 저장할 수 있습니다. 이름·별명, 생년월일·성별, 수유·수면·배설·체온·투약·예방접종·증상 및 메모 중 보호자가 입력한 정보를 기록 조회, 생활 흐름 분석, 리포트에 사용합니다. 가족 계정을 연결하고 동기화를 사용하면 해당 가족의 프로필과 기록을 Supabase 서버에 전송하며, 권한이 있는 가족 구성원이 조회할 수 있습니다. 건강 기록은 광고나 판매 목적으로 사용하지 않습니다.

로그인과 연결 정보

Apple·Google·Kakao의 로그인 식별자, 제공된 이메일과 표시 이름, 앱에서 생성한 계정·설치 식별자, 가족 멤버십을 인증·복구·동기화에 사용합니다. Apple 로그인은 이메일만 요청하며 Apple의 이메일 가리기로 전달된 릴레이 주소도 사용할 수 있습니다. Apple 연결 해제에 필요한 토큰은 서버에서 암호화해 보관합니다. 토큰은 기기나 공개 저장소에 반환하지 않습니다. 기기의 로그인 세션은 iOS Keychain에 보관합니다.

음성·Siri와 사진

앱의 마이크 입력은 기기 내 한국어 음성 인식을 사용합니다. 기기 내 인식을 지원하지 않으면 직접 입력을 제공합니다. 터치베베는 마이크 원음이나 전체 인식 문장을 서버에 자동 전송·보관하지 않습니다. 해석 결과를 확인하고 저장한 돌봄 기록은 다른 기록과 동일하게 처리하며 가족 공유 설정에 따라 동기화될 수 있습니다. Siri와 단축어 자체의 음성 처리에는 Apple의 정책과 기기 설정도 적용됩니다.

사진은 iOS 시스템 선택기에서 보호자가 선택한 항목만 가져옵니다. 위젯 사진과 편집 설정은 앱과 위젯이 사용하는 기기 내 공유 저장소에 보관하며 터치베베 서버에 업로드하지 않습니다. 앱 내 유축 타이머·알림 설정도 기기에 보관합니다. 마이크·음성 인식·알림은 필요한 기능을 선택할 때 권한을 요청하며 거부해도 직접 기록을 사용할 수 있습니다.

서비스 제공자와 국외 처리

Supabase는 계정 인증과 데이터 저장·동기화를 처리합니다. 현재 데이터베이스는 일본 도쿄 리전에 있으며, 가족 공유 및 로그인 시 HTTPS로 필요한 정보를 전송합니다. 서비스 제공자의 보안·운영 로그에 요청 시각·오류, IP 및 IP 기반 대략적 지역이 포함될 수 있습니다. 앱은 GPS 위치 권한을 요청하지 않습니다. Google·Kakao·Apple 로그인 과정에는 각 제공자의 개인정보 정책이 적용됩니다.

GitHub는 공개 안내 페이지와 비공개 암호화 운영 백업을 보관합니다. 복호화 개인 키는 업로드하지 않습니다. Cloudflare의 서버 상태 점검과 운영자가 연결한 Telegram 장애 알림에는 아기 기록 본문을 전송하지 않습니다. 해외 서비스의 처리에는 제공자의 소재지·하위 처리업체가 관여할 수 있습니다. 가족 공유를 사용하지 않고 기기에만 기록하거나, 로그인 연결 해제 및 계정 삭제 요청으로 선택 기능의 이용을 중단할 수 있습니다. 국외 처리에 관한 문의도 위 이메일로 접수합니다.

보관·탈퇴·삭제

서버 계정과 가족 기록은 서비스 제공에 필요한 기간 동안 보관하며, 앱의 가족 또는 관리 화면 → 계정·데이터 삭제 요청에서 삭제할 계정으로 로그인해 요청할 수 있습니다. 접수 번호와 처리 예정일을 확인할 수 있으며 별도의 이메일 발송은 필수가 아닙니다. 운영자가 30일 이내 처리합니다. 접수한 기기에 보관한 비공개 확인 정보로 계정 삭제 후에도 처리 상태를 확인할 수 있고, 이메일을 연결했다면 해당 주소로도 결과를 안내합니다. 앱을 사용할 수 없는 경우 외부 삭제 요청 안내를 이용할 수 있습니다.

삭제 시 연결된 로그인 수단·세션·계정 프로필과 본인이 작성한 서버 기록을 제거하고 Apple 연결을 해제합니다. 다른 보호자가 없는 가족·아기 정보도 삭제합니다. 다른 보호자가 남은 가족과 그 보호자가 작성한 기록은 유지하며 필요한 경우 남은 보호자에게 소유 권한을 넘깁니다. 공유 기기에 삭제 사실을 전달하기 위한 내용 없는 삭제 표식은 남을 수 있습니다. 앱 삭제나 로그아웃만으로 서버 계정이 삭제되지는 않습니다.

운영 데이터베이스의 암호화 백업 보관 기간은 7일입니다. 삭제한 정보가 남은 과거 백업은 보관 기간에 따라 만료되며 복원 시 완료된 삭제 요청을 다시 반영합니다. 삭제 처리·복원 재반영에 필요한 최소 기록은 접근을 제한해 보관하고 목적이 끝나면 제거합니다. 서비스 제공자의 운영 로그는 제공자의 보존 설정에 따릅니다.

기기에만 남은 기록·사진, 사용자가 내보낸 PDF·JSON·CSV와 다른 앱에 공유한 사본은 해당 기기나 저장 위치에서도 관리해 주세요. 보고서 임시 파일은 다음 생성 시 오래된 파일을 정리하며 사용자가 따로 저장한 파일은 지우지 않습니다. 서버 삭제 후 기기 안의 사본이나 다른 보호자가 이미 내보낸 사본을 원격으로 모두 회수할 수는 없습니다.

보호 조치와 권리

HTTPS, 계정·가족별 접근 권한, 입력 검증, 기기 저장소 보호 및 운영 백업 암호화를 적용합니다. 광고 SDK나 추적용 식별자를 사용하지 않습니다. 보호자 또는 법정대리인은 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 본인 확인을 위해 비밀번호, 세션 토큰 또는 아기 건강 기록 전체를 보내실 필요는 없습니다. 정책이 변경되면 공개 페이지의 변경일과 내용을 갱신합니다.

1. 처리하는 정보와 목적

정보목적과 보관 위치
아기 이름·생년월일 등 입력한 프로필, 수유량·모유 수유 시간, 수면·배설·트림·울음, 체온·측정 시각, 투약·예방접종·증상·보호자 메모기록 조회·생활 분석·진료 참고 PDF 제작에 사용합니다. 기본적으로 휴대폰에 보관하며, 가족 공유를 연결하면 해당 가족의 프로필과 기록을 Supabase 서버에 동기화합니다. 연결된 가족은 부여된 권한으로 볼 수 있습니다.
Google·Kakao 로그인 식별자, 이메일 및 로그인 제공자가 전달하는 이름·프로필 정보(프로필 사진 주소 포함), 익명 로그인 식별자, 계정·가족 연결 정보로그인, 기기 간 복원, 가족 권한 확인에 사용합니다. 가족 공유와 개선 의견 전송에는 익명 계정이 사용될 수도 있습니다. 인증 정보는 기기와 인증 서버에서 처리합니다.
앱에서 생성한 임의 기기 식별자와 기기 모델명, 동기화 요청·사용 기록가족 연결·기기 구분·기록 동기화와 오류·접근 통제에 사용합니다. 기기 식별자는 광고 ID나 전화번호가 아닙니다.
위젯에 선택한 사진·문구·편집 설정사진 위젯을 표시하기 위해 기기에 보관합니다. 현재 Android 앱은 선택한 위젯 사진을 가족 서버에 업로드하지 않습니다.
엄마의 유축 기록·타이머·알림 설정, 알림·화면·음성 기능 설정선택한 기능을 실행하기 위해 기기에 보관합니다. 유축 기록은 현재 가족 서버에 동기화하지 않습니다.
직접 작성하고 전송을 선택한 음성 인식 개선 문장, 제출 식별자, 앱·모델 버전, 로그인 식별자와 접수 시각인식 오류를 검토하고 향후 모델을 개선하기 위해 Supabase에 보관합니다. 자동 수집한 음성 원문이 아닙니다.
서버 요청 시각·상태 코드 등 운영 정보, 접속 IP 및 IP에서 추정한 대략적인 지역 등 서비스 제공자가 생성하는 접속 로그서비스 제공·접근 통제·오류 및 부정 사용 대응에 사용합니다. GPS로 위치를 수집하지 않습니다. 운영 알림에는 아기 이름, 기록 내용, 이메일, IP, 음성 원문을 넣지 않고 집계된 상태와 확인 링크만 사용합니다.

현재 Android 앱에는 광고 SDK, 맞춤형 광고, 인앱 결제가 없습니다. 연락처·위치·카메라 촬영 권한을 요청하지 않습니다. 위젯 사진은 시스템 사진 선택 화면에서 사용자가 고릅니다. 변경 시 실제 처리 내용과 안내를 함께 갱신합니다.

2. 음성 기록·접근성 권한

‘빅스비 첫 문장 기록’은 별도의 인앱 공개에 동의하고 Android 접근성 설정에서 직접 켜는 선택 기능입니다. AccessibilityService API로 빅스비 화면의 현재 인식 문장에 포함된 아기 이름·태명, 건강 정보(수유 종류·양·시간, 트림, 수면, 기저귀·배변, 체온, 약 이름·복용량·단위, 증상, 예방접종), 기록 시각과 메모를 읽고 처리합니다. 앱을 열지 않은 상태에서도 빅스비로 말하면 작동하며, 다른 앱 화면 내용은 읽지 않습니다.

이 정보는 아기 기록 자동 저장 및 사용자가 요청한 직전 기록 삭제·시각 수정에 사용합니다. 저장된 기록은 생활 리포트·통계·돌봄 알림에 사용하며, 휴대폰에 저장하고 가족 계정 연결 시 터치베베의 Supabase 서버에 동기화해 연결된 가족이 볼 수 있게 합니다. 광고에 사용하거나 판매하지 않습니다. 기기 안의 JEV 모델과 검증 규칙이 명확한 돌봄 문장만 처리하고 불명확한 내용은 저장하지 않습니다. 동의하지 않아도 직접 기록·예문 체험을 이용할 수 있습니다.

‘기록 후 빅스비 닫기’에 별도로 동의하면 잠금이 풀린 상태에서 새 기록이 저장된 직후, 같은 빅스비 창에 뒤로가기를 한 번 요청합니다. 다른 앱은 닫지 않으며, 이미 시작된 답변이나 다른 앱 실행을 모두 중단하는 기능은 아닙니다.

터치베베는 전체 인식 원문과 원본 음성을 자동 보관·전송하지 않습니다. 메모로 말한 내용은 기록에 저장됩니다. 만들어진 기록과 최근 저장 결과는 앱에 보관되며 가족 공유 설정을 따릅니다. 직접 모아둔 개선 문장은 아래 별도 안내에 따라 처리합니다. 빅스비와 Android 음성 인식 서비스의 음성 처리는 해당 서비스 제공자와 기기의 설정·정책을 따릅니다.

앱 안에서 음성 입력을 선택하면 마이크를 사용합니다. 알림 권한은 돌봄·유축 알림에, ‘알람 및 리마인더’ 설정은 선택한 유축 타이머·알림을 제때 전달하는 데 사용합니다. 거부해도 직접 기록할 수 있습니다.

잠금 상태 기록과 결과 표시는 별도 허용 시에만 사용합니다. 아기 이름이나 기록 결과가 잠금 화면에 표시될 수 있습니다. 저장 결과 음성 안내는 기본 꺼짐이며 사용자가 켜면 기기에서 소리로 안내합니다. 앱의 끄기 기능 또는 Android 설정에서 언제든 권한을 해제할 수 있습니다.

3. 음성 개선 의견

‘업데이트 때 전송하도록 모으기’를 선택한 문장은 기기에 보관한 뒤 이후 앱 업데이트 후 인터넷 연결 시 전송합니다. 이름·연락처·건강 정보 등 개인정보는 문장에 적지 말아 주세요. 아기 이름·가족 식별자·원본 음성·자동 인식 원문은 자동 첨부하지 않습니다.

기기에는 최대 50개, 서버에는 로그인 식별자당 최대 500개를 보관합니다. 전송 전 삭제하면 전송하지 않습니다. 전송 후 ‘기기에서 삭제’는 기기 사본만 삭제하므로 서버 자료 삭제는 아래 문의처에서 요청해 주세요. 서버 자료는 삭제 요청 또는 계정 삭제 시 함께 처리합니다. 다른 앱 사용자에게 공개하거나 자동으로 모델에 학습시키지 않습니다.
